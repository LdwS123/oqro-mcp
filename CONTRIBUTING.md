# Contributing

This repository is documentation for the OQRO MCP server. Fixes to the README, to the tool descriptions or to `server.json` are welcome as pull requests.

- One change per pull request, with a sentence on why.
- Do not add figures or claims about the data that the live server does not show: the README must match <https://oqro.io/.well-known/mcp>.
- A problem with the server itself (a wrong answer, a connection error) belongs in an issue; a security problem belongs in an email (see [SECURITY.md](SECURITY.md)).
